One satirical sentence roasting lawmakers who would regulate AI but cannot convert a file to PDF.

> The lawmakers who wrote 400 pages of AI regulation spent the afternoon calling IT because nobody in the room could turn the bill into a PDF.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is Python 3.13 standard library only. It writes the entry text to `/output/entry.txt`.
